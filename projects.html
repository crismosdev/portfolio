My Projects

Here are some of the projects I built while learning web development fundamentals.

Seed Constraint: “Small Details” — While building these pages, my main focus was on the small details that make a website feel complete: clean semantic tags, a consistent styling and responsive design.

Restaurant Menu Page

This project is a single-page restaurant built to practice HTML document structure and typography. It uses semantic HTML tags to organize the food categories.

Gym Landing Page

I built this promotional page for a fitness center to practice layout design. I learned how to make the layout of the page responsive, as the navigation menu was squeezed and unreadable in a mobile screen.

Boutique Hotel Gallery

This project is a responsive landing page designed to show hotel rooms. I learned how to use a Flexbox container and media queries, which allowed the room images to adapt to different screen sizes without breaking.
