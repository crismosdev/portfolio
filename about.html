About Me

I am Cristina. In August 2024 I started learning web development online, around a full-time job. Evenings were short and some weeks almost disappeared, but I kept going because I wanted a skill I could prove with a real site, not only with tutorials.

This portfolio is that proof: HTML for structure, CSS for layout and visual language, and JavaScript practiced in small projects so I can add behavior with intent.

My Skills

Each rating reflects where I am today, how I picked up the skill, where I put it into practice, and the concrete result you can inspect on this site.

HTML

★ ★ ★ ★ ★

How I learned it: Started with Scrimba's interactive HTML & CSS course in August 2024 and continued my focus on semantic markup and accessibility at Högskolan Kristianstad.

Where I used it: Built the Restaurant Menu Page to organize food categories and structured all six pages of this portfolio.

Evidence of the result: Using semantic landmarks, <figure> and <figcaption> cards in the Gallery and Projects pages, accessible form labels, and aria-current="page" navigation state.

CSS

★ ★ ★ ★ ★

How I learned it: Learned important layout concepts on Scrimba platform, then practiced debugging real responsive issues when elements overflowed or squeezed on smaller screens.

Where I used it: Applied across the Gym Landing Page, the Boutique Hotel Gallery, and the CSS styling in this site.

Evidence of the result: Reusable CSS custom properties, Flexbox and 3-column Grid layouts that adapt at 900px and 600px breakpoints without breaking, and visible keyboard focus outlines.

JavaScript

★ ★ ★ ★ ★

How I learned it: Introduced to programming fundamentals on Scrimba in 2025 and now building deeper DOM and event-handling skills in the HKR JavaScript for Web Development course.

Where I used it: Implemented client-side validation and interactive UI feedback on the Feedback page.

Evidence of the result: Form validation functions showing live error and valid states, plus an accessible confirmation banner using aria-live="polite".

Timeline

My journey into web development is being a gradual process that has been developing during my free time. Here is a look at the specific decisions, difficulties, and outcomes that shaped my progress.

  1. August 2024

    Starting my journey

    I began learning web development using Scrimba's free HTML and CSS course. I decided on this platform because of its fun, project-based approach. I managed to build some very basic projects.

  2. August 2025

    Tackling JavaScript Basics

    I continued practicing in my free time, shifting my focus toward JavaScript also in Scrimba. My biggest difficulty was realizing that JavaScript takes significantly more time and logical thinking to learn compared to plain HTML and CSS. I decided to focus strictly on understanding the absolute basics.

  3. August 2026

    Formalizing Skills at HKR

    To take my skills to the next level, I enrolled in the JavaScript for Web Development course at Högskolan Kristianstad. My decision was driven by a need to move past casual tutorials and learn through a formal academic setting.
